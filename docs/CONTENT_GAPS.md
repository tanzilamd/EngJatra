The normalized library retains all original records. The 932 canonical vocabulary IDs are reused for exact matching unit senses; 169 unit entries whose gloss/link does not match a canonical source sense keep stable unit-specific keys. This avoids silently conflating meanings or assigning unverified canonical mappings. The combined saved-sense inventory can cover these 1,101 distinct keys within the 1,500-word state bound.

Review priorities are natural English/Bangla meanings, acceptable alternate answers, inference evidence, culturally clear examples, longer higher-band writing and source licensing. Listening/speaking links are honest external practice, not recorded assessment. Semantic corrections need explicit editorial judgment and regression tests; no source data was automatically rewritten during this implementation.

The small 3.0.1 supplement is defined in `content/releases/3.0.1.json`, anchored to exact original sentences/senses and validated by regression tests. All 96 unit bytes, stable IDs, existing answers and the 3.0.0 library remain unchanged. Seven examples focus on everyday beginner greetings, relationships and polite requests. Remaining vocabulary examples and longer reading coverage are real editorial work, not a missing-credential excuse; extend them in reviewed, useful batches rather than bulk filler. Existing authored lessons/conversations remain usable while that coverage grows.
