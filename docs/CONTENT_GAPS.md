The normalized library retains all original records. This avoids silently conflating meanings or assigning unverified canonical mappings. The combined saved-sense inventory can cover these 1,101 distinct keys within the 1,500-word state bound.

Review priorities are natural English/Bangla meanings, acceptable alternate answers, inference evidence, culturally clear examples, longer higher-band writing and source licensing. Listening/speaking links are honest external practice, not recorded assessment. Semantic corrections need explicit editorial judgment and regression tests; no source data was automatically rewritten during this implementation.
